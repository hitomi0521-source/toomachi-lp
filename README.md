# とおまち 夏花火ナイト LP

## ファイル構成

```
toomachi-lp/
├── index.html        … LP本体
├── reserve.html      … 観覧席の予約ページ（入力 → 確認 → 完了）
├── favicon.ico       … ファビコン（ともりん）
├── css/
│   ├── style.css     … LPのスタイル
│   └── reserve.css   … 予約ページのスタイル
├── js/
│   ├── main.js       … LPの動き（動画・アニメーション・FAQ・追従ボタン）
│   └── reserve.js    … 予約フォームの動き（入力チェック・GASへの送信）
├── images/           … 画像（WebP・OGP用JPEG・ホーム画面用アイコン）
├── videos/           … FVの背景動画（スマホ用・PC用）
└── gas/Code.gs       … スプレッドシート連携用のGoogle Apps Script
```

※ index.html の head にある1行の `<script>` だけは、表示前に動かす必要があるため、HTMLに残しています。

`reserve.html` は、GASのURLを設定する前でも **デモモード** で動きます。
送信ボタンを押すと、通信はせずに完了画面（予約番号 `TM-DEMO01`）まで進むので、画面の流れだけ先に確認できます。

## GASの設定手順

### 1. スプレッドシートを作る
1. Googleドライブで新しいスプレッドシートを作成（名前は「とおまち観覧席 予約」など）
2. メニューの **拡張機能 → Apps Script** を開く

### 2. コードを貼り付ける
1. 最初から入っている `function myFunction() {}` を消す
2. `gas/Code.gs` の中身を全部貼り付けて保存（Ctrl+S / ⌘+S）
3. 必要なら先頭の `CONFIG` を書き換える
   - `CAPACITY`：観覧席の総数（今は仮で200）
   - `ADMIN_EMAIL`：予約が入ったときに通知を受け取るアドレス（空なら通知なし）
   - `LINE_URL`：`{LINE_ID}` を公式LINEのIDに

### 3. 初期設定を実行する
1. エディタ上部の関数選択で **setup** を選んで「実行」
2. 初回は権限の確認が出るので、次の順に許可する
   - 「権限を確認」→ 自分のGoogleアカウントを選ぶ
   - 「このアプリはGoogleで確認されていません」と出たら **詳細 → （プロジェクト名）に移動（安全ではないページ）**
   - 「許可」
3. スプレッドシートに「予約」シートと見出し行ができていればOK

### 4. （任意）テスト送信
1. `testReservation` 関数の `MY_EMAIL` を自分のアドレスにして保存
2. 関数選択で **testReservation** を選んで実行
3. シートに1行追加され、予約完了メールが届けばOK（確認後、その行は削除してかまいません）

### 5. ウェブアプリとしてデプロイする
1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車アイコン → 種類で **ウェブアプリ** を選ぶ
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー

### 6. js/reserve.js にURLを入れる
`js/reserve.js` の上の方にある次の行を、コピーしたURLに書き換えます。

```js
const GAS_URL = '{GAS_URL}';
```

これで、予約ページからの送信がスプレッドシートに記録されます。

## 運用のしかた

| やりたいこと | 方法 |
|---|---|
| キャンセルを受けた | その行の「ステータス」を **キャンセル** にする → 席が自動で戻る |
| 当日、受付した | 「ステータス」を **来場済み** にする（席数には含めたまま） |
| 席数を変えたい | `CONFIG.CAPACITY` を変更して保存 → **デプロイを管理 → 編集 → バージョン：新しいバージョン → デプロイ** |

## つまずきやすいところ

- **コードを直したのに反映されない**
  GASは、デプロイし直さないと古いコードのまま動きます。
  「デプロイを管理」→ 鉛筆アイコン → バージョンで「新しいバージョン」を選んでデプロイしてください（URLは変わりません）。
  「新しいデプロイ」を選ぶとURLが変わるので、その場合は `js/reserve.js` の `GAS_URL` も書き換えが必要です。
- **「通信エラーで送信できませんでした」と出る**
  - アクセスできるユーザーが「全員」になっているか
  - `js/reserve.js` の `GAS_URL` が `/exec` で終わっているか（`/dev` は本人しか使えません）
- **メールが届かない**
  - 迷惑メールフォルダを確認
  - 無料のGoogleアカウントは、1日に送れるメールが約100通までです。超えるとシートの「予約完了メール」列に「送信失敗」と記録されます（予約自体は成立しています）
- **予約完了メールの差出人**
  メールは、スクリプトを動かしているGoogleアカウントから送られます。
